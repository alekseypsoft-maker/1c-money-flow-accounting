# 1С: Учет движения денежных средств и валют

Практическая демонстрационная конфигурация на платформе **1С:Предприятие 8.3**, показывающая, как можно организовать учет движения денежных средств, работу с валютами, переводы между кошельками и получение текущих остатков с помощью отчета на СКД.

Проект построен вокруг понятного бизнес-сценария: пользователь работает с денежными кошельками, фиксирует поступления и списания, переводит деньги между кошельками, использует разные валюты и контролирует актуальные остатки.

## Зачем нужен этот проект

Проект позволяет увидеть не отдельный фрагмент кода 1С, а связанный пример прикладного решения, в котором несколько механизмов платформы работают вместе.

На его основе можно изучить, как в конфигурации 1С организуется полный цикл обработки денежных операций:

**справочники → документы → движения по регистру → хранение курсов валют → серверная бизнес-логика → отчетность на СКД.**

Это делает проект полезным для тех, кто хочет не просто посмотреть синтаксис BSL, а разобраться, как отдельные объекты 1С объединяются в работающую прикладную подсистему.

## Что можно получить из проекта

### 1. Готовый пример прикладной архитектуры 1С

Репозиторий показывает распределение ответственности между основными объектами конфигурации:

* справочники хранят постоянные данные;
* документы фиксируют хозяйственные операции;
* регистр накопления хранит движения и состояние денежных средств;
* регистр сведений хранит курсы валют;
* общий модуль содержит серверную логику работы с валютами;
* отчет на СКД предоставляет пользователю информацию об остатках.

Такой пример можно использовать как ориентир при создании собственных небольших прикладных решений.
