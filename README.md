# 1С: Учет движения денежных средств и валют

Практическая демонстрационная конфигурация на платформе **1С:Предприятие 8.3**, показывающая, как можно организовать учет движения денежных средств, работу с валютами, переводы между кошельками и получение текущих остатков с помощью отчета на СКД.

Проект построен вокруг понятного бизнес-сценария: пользователь работает с денежными кошельками, фиксирует поступления и списания, переводит деньги между кошельками, использует разные валюты и контролирует актуальные остатки.

## Зачем нужен этот проект

Проект позволяет увидеть не отдельный фрагмент кода 1С, а связанный пример прикладного решения, в котором несколько механизмов платформы работают вместе.

На его основе можно изучить, как в конфигурации 1С организуется полный цикл обработки денежных операций:

**справочники → документы → движения по регистру → хранение курсов валют → серверная бизнес-логика → отчетность на СКД.**

Это делает проект полезным для тех, кто хочет не просто посмотреть синтаксис BSL, а разобраться, как отдельные объекты 1С объединяются в работающую прикладную подсистему.

## Что можно получить из проекта

### 1. Готовый пример прикладной архитектуры 1С

Репозиторий показывает распределение ответственности между основными объектами конфигурации:

* справочники хранят постоянные данные;
* документы фиксируют хозяйственные операции;
* регистр накопления хранит движения и состояние денежных средств;
* регистр сведений хранит курсы валют;
* общий модуль содержит серверную логику работы с валютами;
* отчет на СКД предоставляет пользователю информацию об остатках.

Такой пример можно использовать как ориентир при создании собственных небольших прикладных решений.

### 2. Практический пример учета движения денег

В конфигурации предусмотрены основные операции:

* поступление денежных средств;
* списание денежных средств;
* перевод денег между кошельками.

Это позволяет посмотреть, как хозяйственная операция пользователя превращается в движения по регистру накопления.

### 3. Мультивалютный учет

Проект содержит механизм работы с валютами и хранения курсов.

Это позволяет изучить организацию данных, необходимых для операций в разных валютах, и посмотреть, как выделение валютной логики в отдельный общий модуль помогает не дублировать код в разных объектах конфигурации.

### 4. Работа с регистрами 1С

Регистр накопления **«Остатки денежных средств»** используется для хранения информации, необходимой для контроля состояния денежных средств.

На примере этого регистра можно разобраться с тем, как документы формируют движения и как накопленные данные затем используются для получения текущих остатков.

### 5. Документы и проведение

Проект показывает практический сценарий использования документов для регистрации денежных операций.

Можно изучить структуру документов:

* **Поступление**
* **Списание**
* **Перевод денег**

и посмотреть, как прикладная операция пользователя связана с изменением данных регистра накопления.

### 6. Отчетность на СКД

В проект включен отчет **«Остатки кошельков»**, построенный на схеме компоновки данных.

Это позволяет увидеть полный путь от накопленных данных до пользовательского отчета:

**операция → движение регистра → запрос данных → СКД → отчет пользователю.**

Такой пример может быть полезен разработчикам, которые изучают практическое применение СКД в прикладных конфигурациях.

# Функциональные возможности

## 💰 Учет денежных средств

Система позволяет фиксировать основные операции движения денежных средств:

* поступление;
* списание;
* внутренний перевод между кошельками.

Денежные операции отражаются в информационной базе и используются для последующего контроля состояния денежных средств.

## 💱 Мультивалютный учет

В конфигурации предусмотрены:

* справочник валют;
* хранение курсов валют;
* использование валют при проведении операций;
* общий модуль для работы с валютной логикой.

Это даёт возможность изучить организацию отдельного прикладного механизма, отвечающего за работу с валютами.

## 👛 Кошельки

Справочник кошельков используется для представления мест хранения денежных средств.

Через кошельки можно моделировать различные источники и места хранения денег и выполнять внутренние переводы между ними.

## 📊 Аналитика денежных операций

Для классификации движения денежных средств предусмотрены статьи движения денежных средств.

Это позволяет связывать операции с соответствующими категориями и использовать эти данные при дальнейшей аналитике.

## 📈 Контроль остатков

Отчет **«Остатки кошельков»** позволяет получить информацию о текущем состоянии денежных средств.

Отчет построен с использованием **схемы компоновки данных (СКД)**.

# Структура проекта

```text
Catalogs/
├── Валюты
├── Кошельки
├── Статьи ДДС
└── Товары

Documents/
├── Поступление
├── Списание
└── Перевод денег

AccumulationRegisters/
└── Остатки денежных средств

InformationRegisters/
└── Курсы валют

Reports/
└── Остатки кошельков

CommonModules/
└── Работа с валютами

Subsystems/
└── Функциональность системы
```

## Catalogs

Справочники содержат основные постоянные данные, используемые прикладным решением:

* валюты;
* кошельки;
* статьи ДДС;
* товары.

## Documents

Документы представляют операции пользователя:

* поступление денежных средств;
* списание денежных средств;
* перевод денежных средств между кошельками.

## AccumulationRegisters

Регистр накопления **«Остатки денежных средств»** предназначен для накопления информации о состоянии денежных средств и последующего получения актуальных остатков.

## InformationRegisters

Регистр сведений **«Курсы валют»** используется для хранения информации о курсах валют.

## Reports

Отчет **«Остатки кошельков»** демонстрирует получение прикладной информации из накопленных данных с использованием СКД.

## CommonModules

Общий модуль **«Работа с валютами»** содержит серверные функции, связанные с валютной логикой.

Выделение такой логики в общий модуль позволяет использовать её из нескольких объектов конфигурации и уменьшать дублирование прикладного кода.

## Subsystems

Подсистема объединяет функциональность решения и формирует пользовательскую точку доступа к реализованным возможностям.

# Чему можно научиться на этом проекте

Проект можно использовать как небольшую практическую лабораторию по разработке прикладной конфигурации 1С.

На его основе можно изучить:

* структуру конфигурации 1С;
* взаимодействие справочников и документов;
* проведение документов;
* формирование движений регистров;
* использование регистров накопления;
* использование регистров сведений;
* организацию мультивалютного учета;
* выделение серверной логики в общие модули;
* построение отчетов на СКД;
* организацию подсистем;
* моделирование операций движения денежных средств.

Главное преимущество такого примера в том, что эти механизмы представлены **не изолированно, а в рамках одной предметной области**.

Например, разработчик может проследить путь одной операции:

**Пользователь → документ → проведение → движения регистра → остаток → отчет.**

Так становится понятнее, какую роль каждый объект конфигурации играет в общем процессе.

# Практический сценарий работы

Типовой сценарий использования конфигурации выглядит следующим образом:

1. Создать или выбрать кошелек.
2. Выбрать валюту.
3. Зафиксировать поступление денежных средств.
4. При необходимости выполнить списание.
5. Выполнить перевод денег между кошельками.
6. Получить актуальные остатки.
7. Проанализировать результат через отчет.

Такой сценарий позволяет увидеть взаимосвязь между пользовательскими операциями и внутренними объектами конфигурации.

# Как развернуть проект

### Требования

* **1С:Предприятие 8.3**
* рекомендуется версия **8.3.15 и выше**.

### Загрузка конфигурации

1. Создайте пустую информационную базу в стартере 1С.

2. Откройте базу в режиме **Конфигуратор**.

3. Выберите:

   **Конфигурация → Открыть конфигурацию**

4. Выберите:

   **Конфигурация → Загрузить конфигурацию из файлов...**

5. Укажите корневую директорию данного репозитория.

6. После загрузки обновите конфигурацию базы данных с помощью **F7**.

7. Запустите информационную базу в режиме **1С:Предприятие**.
