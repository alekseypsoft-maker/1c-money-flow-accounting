## Money Flow 1C
Учебная или демонстрационная конфигурация на платформе «1С:Предприятие 8.3» для учета и контроля движения денежных средств. 
## 📌 Функционал системы
* Мультивалютный учет: Хранение курсов валют и проведение операций в различных валютах.
* Учет денежных средств: Фиксация поступлений, списаний и внутренних перемещений между кошельками.
* Аналитика: Классификация затрат и доходов по статьям движения денежных средств.
* Отчетность: Контроль актуальных остатков на кошельках через отчет на базе СКД.

## 📁 Структура проекта

* Catalogs/ — справочники: Валюты, Кошельки, Статьи ДДС, Товары.
* Documents/ — документы: Поступление, Списание и Перевод денег.
* AccumulationRegisters/ — регистр накопления «Остатки денежных средств».
* InformationRegisters/ — регистр сведений «Курсы валют».
* Reports/ — отчет «Остатки кошельков» на схеме компоновки данных (СКД).
* CommonModules/ — общий модуль «Работа с валютами» для серверных функций.

## 🛠 Требования
* Платформа «1С:Предприятие 8.3» (рекомендуется версия 8.3.15 и выше).

## 🚀 Как развернуть проект
   1. Создайте пустую информационную базу в стартере 1С.
   2. Откройте базу в режиме Конфигуратор.
   3. В главном меню выберите: Конфигурация -> Открыть конфигурацию.
   4. Перейдите в Конфигурация -> Загрузить конфигурацию из файлов....
   5. Укажите путь к корневой директории данного репозитория (~/money-flow-1c).
   6. Обновите конфигурацию базы данных (клавиша F7).
